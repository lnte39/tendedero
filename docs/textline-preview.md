# Textline Preview 本机验收

这是用户 fork 的独立 macOS 测试包。它有自己的名称、图标、偏好设置和文件目录，不覆盖已安装的 Tendedero。支持 macOS 14 及以上，按构建主机架构打包；目前在 Apple silicon 上验证，未验证 Intel 或 Windows。

## 启动

在仓库中构建到 `build` 目录，然后自行启动：

```sh
bash scripts/build-preview.sh "$PWD/build"
open "build/Textline Preview.app"
```

如果已经构建，请直接打开输出目录中的 `Textline Preview.app`；脚本会拒绝覆盖已有应用，可选用新的输出目录。

这是菜单栏应用。找到**文字气泡图标**，鼠标悬停应显示 **Textline Preview**。原版仍使用衣服图标。若原版同时运行导致默认快捷键冲突，使用新应用菜单中的“显示晾衣绳”；也可以自行暂时退出原版。

本包只做本地 ad-hoc 签名，没有公证。若 macOS 阻止打开，请记录具体提示再反馈，不必修改系统安全设置。

## 文字验收

1. 初次启动时，“挂上复制的文字”和“挂上复制的图片”均应未勾选。先在 TextEdit 等应用复制一段合成文字，晾衣绳不应新增条目。
2. 在 **Textline Preview** 菜单勾选“**挂上复制的文字**”。仅启用开关不应自动导入已有剪贴板。
3. 重新复制下面这段样例，等待约半秒；通过菜单“显示晾衣绳”查看文字卡片。

   ```text
   你好，世界 👩🏽‍💻
   第二行：Café / Café
   https://example.test/?a=1&b=2
   ```

4. 点击文字卡片，再粘贴到新的空白文本窗口。应得到完整文字，保留换行、空格和 emoji，而不是截图或 `.txt` 文件路径。卡片不应因这次复制而重复出现。
5. 退出并重新启动 **Textline Preview**，卡片应恢复；文字开关会记住你上次的选择。再点击卡片验证复制。开关保持开启时只接收启动后的新复制，不导入启动前内容。
6. 取消勾选“挂上复制的文字”，再次复制样例，不能产生新卡片。验收完可保持关闭并退出。

可选：用合成图片验证“挂上复制的图片”独立开关；调整“绳上保留”数量，验证新旧条目顺序和移除行为。文字条目使用 Quick Look 预览，不提供图片涂画，也没有 OCR。

## 保存与范围

- 偏好设置域：`io.github.lnte39.TextlinePreview`。
- 保存目录：`~/Library/Application Support/TextlinePreview/Screenshots/`。开启文字开关后，接收到的内容会保存在本机，文件名不含正文。
- 单条最多 **1 MiB UTF-8**，拒绝空字符串、NUL、多个剪贴板条目以及带隐私/临时标记的内容；富文本仅保留纯文本。
- 关闭文字开关不会删除已保存卡片。删除或超过容量时，应用自有目录中的文件沿用原版行为移到废纸篓，不是安全擦除。
- 初次启动只监视自己的目录，不读取原版保存目录，也不默认监视桌面或弹出截图接管提示。若你另行启用“接管截图”或选择附加文件夹，会执行对应的原有功能；文字验收不需要启用它们。
- 自动化测试使用合成文本、独立测试剪贴板和临时目录，不读取真实剪贴板。文字工作流已完成本机人工冒烟验收；Quick Look、拖拽和系统废纸篓等交互仍建议按自己的环境检查。

## 从源码重新打包

在 fork 仓库中运行，输出目录须为绝对路径：

```sh
bash scripts/build-preview.sh /absolute/output/directory
```

脚本使用正常工具链构建本机架构，绘制原创图标、复制九种语言和许可文件、做本地 ad-hoc 签名。若输出中的 `Textline Preview.app` 已存在会拒绝覆盖。不要用上游 `build-app.sh` 给这个修改版打包，因为它仍使用原版名称和图标。
