# Plain-text clipboard support: validation

This change adds macOS plain-text capture, persistence and copying, with a
separate default-off switch. It does not add OCR or Windows support.

## Run the checks

Use a compatible macOS Swift toolchain; no third-party dependencies or XCTest
installation are required.

```sh
swift package describe
swift build -c debug
swift build -c release
bash scripts/check-text.sh
bash scripts/check-preview.sh
swift scripts/check-strings.swift
bash scripts/build-preview.sh "$PWD/build"
git diff --check
```

The preview build refuses to overwrite an existing `Textline Preview.app`.
Choose a fresh absolute output directory for subsequent packages. It builds
the host architecture, includes the license and translations, and verifies its
local ad-hoc signature without using a signing identity.

## Coverage

`check-text.sh` compiles the app sources with the main entry point excluded.
Its **13 checks** cover:

- Default-off/start/stop behavior and capture of new copies only.
- Independent image-only and text-only modes.
- Exact Unicode, emoji, whitespace and line-ending round trips.
- Owner-only files and restart restoration.
- Concealed, transient, autogenerated and file-copy markers.
- Plain-text fallback from rich text, including URL text.
- Multi-item rejection and exact-byte duplicate suppression.
- Empty/NUL/oversized text and invalid or missing backing files.
- Capacity, ordering and removal alongside images.
- Existing image capture/copy representations and cancelled image callbacks.
- Bounded thumbnail rendering without changing the stored text.

All clipboard operations use unique named test pasteboards. Files and
preferences use disposable test locations. The runner does not read the
general clipboard, start the application, or touch the user's Trash.

`check-preview.sh` runs **two checks** using a small Foundation-only executable:
ordinary identity/storage and preview identity/storage. It also verifies the
localized display-name substitution. It does not run the main application.

`check-strings.swift` validates **59 strings in nine languages**. Packaging
checks the property list and signed bundle structure. [Manual acceptance
steps](textline-preview.md) cover the menu, copying, persistence and opt-out.

## Verified environment and limits

- Verified on Apple silicon, macOS 14.8.3, Swift/SwiftPM 6.0.3 and SDK 15.2.
- Debug and release builds passed; all 13 clipboard and two identity checks
  passed. Translation and bundle signature checks passed.
- A user accepted the macOS text workflow in a local manual smoke check.
- Existing concurrency warnings in `LineView` and `Trim` remain; the package
  uses Swift 5 language mode. This change is not a Swift 6 migration.
- The preview is locally signed, not notarized. Intel, Windows and all
  Quick Look/drag-and-drop/Trash edge cases are not claimed as verified.
- Saved text follows the existing capacity/removal rules. Removing inbox
  items moves them to Trash rather than securely erasing their contents.
